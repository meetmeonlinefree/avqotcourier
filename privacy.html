Политика конфиденциальности для курьеров AVQOT

Дата последнего обновления: 1 декабря 2025 г.

Приложение AVQOT («мы») обрабатывает ваши персональные данные в связи с оказанием услуг по доставке заказов. Эта Политика объясняет, какие данные мы собираем, как их используем и защищаем.

1. Какие данные мы собираем

  • Персональные данные: ФИО, номер телефона, данные паспорта/водительского удостоверения (при регистрации).
  • Данные о транспорте: марка, модель, госномер (если используете личное авто).
  • Геолокационные данные: текущее местоположение во время выполнения заказов.
  • Данные о заказах: история доставок, время прибытия, статус выполнения.
  • Платёжные данные: реквизиты счёта для выплат (банковские/электронные).

2. Как мы используем ваши данные

  1. Для назначения вам заказов и координации доставки.
  2. Для расчёта и перечисления оплаты за выполненные заказы.
  3. Для связи по вопросам маршрутов, заказов или инцидентов.
  4. Для анализа эффективности работы и улучшения сервиса.
  5. Для соблюдения требований законодательства (налоги, отчётность).

3. С кем мы делимся данными

Мы не передаём ваши персональные данные третьим лицам без вашего согласия, кроме случаев:

  • Ресторанов (только адрес доставки и контактный номер клиента для передачи заказа).
  • Платёжных систем (реквизиты для выплат).
  • Государственных органов (по законному запросу).

4. Защита данных

  • Шифрование передачи данных (HTTPS, SSL).
  • Ограниченный доступ сотрудников к персональным данным.
  • Хранение данных на защищённых серверах.
  • Регулярные аудиты безопасности.

5. Ваши права

  • Доступ к своим данным.
  • Исправление неточных сведений.
  • Удаление данных (с учётом обязательств по выплатам и закону).
  • Отзыв согласия на обработку (с последствиями для работы в системе).

6. Отслеживание местоположения

Геолокация используется:

  • Для назначения ближайших заказов.
  • Для отображения статуса доставки клиенту и ресторану.
  • Для расчёта времени в пути и оптимизации маршрутов.

Вы можете отключить геолокацию в настройках устройства, но это ограничит вашу работу в приложении.

7. Изменения в Политике

Мы уведомляем о изменениях через приложение. Актуальная версия всегда здесь.
